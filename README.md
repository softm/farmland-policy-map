# 농지안심맵 · Farmland Policy Map

지도에서 내 농지의 위치, 정책 확인사항, 활용기회, 증빙자료를 관리하는 GitHub Pages 웹 앱입니다.

[서비스 열기](https://softm.github.io/farmland-policy-map/) · [전체 프로젝트](https://softm.github.io/projects/) · [구현 명세](docs/IMPLEMENTATION.md)

## 실행

Node.js 22 이상, Python 정적 서버. npm 런타임 의존성은 없습니다.

```sh
npm test
npm run check
npm run build
npm run dev
```

`npm run dev`는 http://localhost:4173 에서 실행합니다. `file://` 대신 HTTP 서버를 사용하세요.

## 구현 기능

| 영역 | 구현 |
|---|---|
| 지도 | 네이버 Maps v3 (기본 위성·도로 혼합지도), 현재위치, 좌표 검색, 주요 지역 이동, 등록 마커, 상태 필터 |
| 농지 | 주소·PNU·면적·취득·경작·임대·시설·서류 대조·조사 통지·제출기한 입력/수정/삭제 |
| 점검 | 결정형 규칙, 이유·다음 할 일·공식 출처, 체크 완료 저장, KST 기준 기한 표시 |
| 혜택 | 입력현황별 농지은행·상속농지 관리·경영체/지원사업 상담 경로. 승인 확정 아님 |
| 증빙 | JPG/PNG/WebP/PDF 원본 첨부(8MB/건), 메모, 원본 저장, SHA-256 내용 해시 |
| 보고서 | 점검·활용기회·증빙 목록 및 이미지 인쇄. PDF 파일 자체 병합은 하지 않음 |
| 데이터 | IndexedDB 로컬 저장, 원본 포함 JSON 백업/병합 복원, 연결 증빙 삭제 |
| 화면 | 데스크톱 지도·사이드바, 모바일 하단 상세 패널, 정책 카드, 폼·키보드 조작 |
| 배포 | main → 테스트/빌드 → 기존 gh-pages 소스에 게시 → Pages 빌드 요청 → 운영 브라우저 검증 |

## VWorld API 설정

배경지도·수동 농지등록·점검·증빙은 별도 키 입력 없이 기본 설정으로 작동합니다. 주소·지번 검색은 네이버 Geocoder로 전환했습니다. 지적도·농업진흥지역 등 WMS 레이어에는 VWorld 키가 필요합니다.

1. [VWorld](https://www.vworld.kr/)에서 `https://softm.github.io`를 허용한 도메인 제한 키를 발급합니다.
2. 앱 상단 **설정·백업**에서 키와 등록 도메인을 입력하고 레이어를 선택합니다.
3. 주소 검색과 영상 응답을 확인합니다. 연속지적도는 확대 수준 15 이상에서 요청합니다.

레이어: `lp_pa_cbnd_bubun,lp_pa_cbnd_bonbun`(연속지적도), `lt_c_agrixue101`(농업진흥지역), `lt_c_agrixue102`(영농여건불리농지).

키는 코드/백업에 포함하지 않고 브라우저에 저장합니다. 브라우저용 키에는 도메인·서비스 제한이 필요합니다. **API 호출 코드는 구현했지만 실발급 키가 없어 실제 응답은 미검증입니다.**

## 범위와 주의사항

지도 마커는 사용자 등록 위치이며 지적경계·소유권 확인 결과가 아닙니다. 가상 예시도 실제 필지가 아닙니다. 농지대장·경영체·직불금 DB 자동 열람, PNU 피처 자동조회, 경사/접근성 분석은 후속 연동이 필요합니다.

공인 조사 확률·임의 100점 위험도를 만들지 않습니다. `정보 보완 / 조건 검토 / 우선 확인 / 기본 점검`은 입력에 따른 작업 분류입니다. 상속농지 총면적, 고령농의 자경기간·거주지역 등 예외의 전체 요건이 확인되지 않으면 적법성을 확정하지 않습니다. 미확인 전수조사 유예·정상화 기한은 자동 규칙에 넣지 않았습니다. 정책은 검토일 **2026-10-05** 기준 정적 안내이며 실시간 수집·푸시 알림이 아닙니다.

## 개인정보

입력 데이터는 기기의 IndexedDB에 보관되며 앱 운영 서버에 업로드하지 않습니다. **로그인·암호화·서버 백업·기기 간 동기화가 없습니다.** 같은 `softm.github.io` 출처의 다른 코드도 저장소에 접근할 수 있으므로 민감문서/주민등록번호를 보관하지 말고 공용기기에서 사용하지 마세요. 별도 백업이 필요합니다.

네이버 Maps은 지도 표시를 위해 IP·참조 도메인 등을 받을 수 있습니다. VWorld 연결 후에는 검색어·좌표·키·도메인이 해당 서비스로 전달됩니다. 현재위치는 사용자 버튼과 브라우저 권한을 거칩니다. 지도 대량수집/오프라인 타일 다운로드를 하지 않으며 서비스워커는 앱 정적 파일만 처리합니다.

## 운영 브라우저 검증

```sh
pip install playwright
python -m playwright install chromium
APP_URL=https://softm.github.io/farmland-policy-map/ REQUIRE_MAP=1 python tests/browser_smoke.py
```

실제 지도, 농지 등록, 점검/할 일 저장, 새로고침 보존, 증빙, 백업, 정책 필터, 모바일 가로넘침, 삭제·복원을 검사합니다. 테스트 기록은 검증 브라우저 안에만 저장됩니다. 실행 결과와 화면은 GitHub Actions `browser-verification` artifact에 남깁니다.

## v0.2.0 네이버 지도 전환

사용자 요청에 따라 `softm/homecare-nationwide-care-services-map`의 지도 흐름과 UI를 참고했습니다. 참고 커밋: `263fddd1393cae2fc840d64a3fc80c353c1fcdb3`.

- 네이버 SDK+Geocoder, 기본 HYBRID, 일반지도 전환, 확대/축소/현재위치.
- 현재 지도영역 자동 조회(저장 농지 기준), 수동 재조회, 전체/현재영역, 정렬, 지도 모두 표시 체크박스.
- 동일 목록 번호의 상태 마커, 선택 강조, 선택 시 목록 순번 보존, 지도 위치·배율 탭 세션 유지.
- 모바일 지도 검색창·접이식 목록·하단 상세 패널. 기존 농지/증빙 DB는 변경하지 않았습니다.
- 참고 저장소의 공개 브라우저 ID를 기본 사용하며 Client Secret은 사용하지 않습니다. Maps Application에 현재 Origin이 허용되어야 하며 같은 ID 사용량을 공유합니다. 네이버 API 실패를 OSM 성공으로 가장하지 않습니다.
- VWorld WMS는 네이버 GroundOverlay로 표시하며 경계/소유권 공식 판정이 아닙니다.
